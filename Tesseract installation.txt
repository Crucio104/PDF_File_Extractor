==================================================
TESSERACT OCR INSTALLATION GUIDE
==================================================

Tesseract OCR is required for text recognition from images in the PDF Reader application.

INSTALLATION INSTRUCTIONS BY OPERATING SYSTEM:

--------------------------------------------------
WINDOWS
--------------------------------------------------

METHOD 1: Using Chocolatey (Recommended)
1. Install Chocolatey (if not already installed):
   - Open PowerShell as Administrator
   - Run: Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

2. Install Tesseract:
   - Run: choco install tesseract -y

METHOD 2: Manual Installation
1. Download installer from: https://github.com/UB-Mannheim/tesseract/wiki
2. Run the .exe installer
3. Add Tesseract to PATH (usually installed to: C:\Program Files\Tesseract-OCR\)
4. Restart your terminal/command prompt

VERIFICATION:
- Open Command Prompt and type: tesseract --version

--------------------------------------------------
macOS
--------------------------------------------------

METHOD 1: Using Homebrew (Recommended)
1. Install Homebrew (if not already installed):
   - Run: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2. Install Tesseract:
   - Run: brew install tesseract

METHOD 2: Using MacPorts
1. Install MacPorts (if not already installed)
2. Run: sudo port install tesseract

VERIFICATION:
- Run: tesseract --version

--------------------------------------------------
LINUX (Ubuntu/Debian)
--------------------------------------------------

1. Update package list:
   - sudo apt update

2. Install Tesseract:
   - sudo apt install tesseract-ocr

3. Install additional language packs (optional):
   - sudo apt install tesseract-ocr-eng tesseract-ocr-ita tesseract-ocr-fra tesseract-ocr-deu tesseract-ocr-spa

VERIFICATION:
- Run: tesseract --version

--------------------------------------------------
LINUX (CentOS/RHEL/Fedora)
--------------------------------------------------

For Fedora:
- sudo dnf install tesseract

For CentOS/RHEL:
- sudo yum install tesseract

--------------------------------------------------
DOCKER
--------------------------------------------------

If using Docker, add to your Dockerfile:
- RUN apt-get update && apt-get install -y tesseract-ocr

==================================================
CONFIGURATION IN PYTHON CODE
==================================================

After installation, you may need to configure the path in your Python code:

import pytesseract

# For Windows (if not in PATH):
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

# For Linux/macOS (usually automatically detected)

==================================================
TROUBLESHOOTING
==================================================

COMMON ISSUES:

1. "tesseract is not recognized as a command"
   - Solution: Add Tesseract installation directory to your system PATH

2. Python cannot find tesseract
   - Solution: Set the path manually as shown above

3. Language data missing
   - Solution: Install additional language packs

TEST INSTALLATION:
- Run: tesseract --list-langs
- This should show available languages (eng should be included)

==================================================
ADDITIONAL LANGUAGE PACKS
==================================================

To install additional languages:

Windows (with Chocolatey):
- choco install tesseract-languages

Linux (Ubuntu/Debian):
- sudo apt install tesseract-ocr-all

macOS (with Homebrew):
- brew install tesseract-lang
